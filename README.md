# Shopping List

A web app for your grocery list: add items, tick off what you've bought, and take the list with you to the store.

**Live app:** https://justelven.github.io/shopping-list/

> A learning project: I'm building it from scratch to learn HTML, CSS and JavaScript.

## Features

- [x] Add items with an optional quantity (for example `Milk`, `2 l`)
- [x] Mark items as bought, remove them one by one, or clear all bought items at once
- [x] Progress bar and counters: total items and how many are bought
- [x] Automatic section detection from the item name (see below)
- [x] Sections with a custom order: drag to reorder, swipe left to delete, add your own
- [x] Saved section orders: store several orders (for example one per store) and switch between them from the main screen
- [x] Light and dark theme (follows the system setting until you pick one)
- [x] Save the list in the browser (`localStorage`)
- [x] Backup: download the list as a JSON file and restore it later
- [ ] Offline support (PWA)

## How section detection works

When you type an item name, the app picks a section in three steps, from the most precise to the most general:

1. **Your corrections.** If you change the suggested section by hand, the app remembers it for that item name.
2. **Keyword dictionary.** The longest matching keyword wins (for example, "молок" → Dairy & eggs).
3. **Small ML model.** If no keyword matches, a logistic regression model from `model.js` makes a guess.

If the model isn't sure either, the item goes to the "Разное" (Misc) section, which can't be deleted.
You can always change the section in the dropdown before adding the item.

The interface and the keyword dictionary are in Russian.

## Using it on your phone

The live app is published with GitHub Pages, so a domain is not needed.

1. Open https://justelven.github.io/shopping-list/ on your phone.
2. Add it to the home screen: in Safari tap Share → Add to Home Screen, in Chrome choose Install app.

Good to know:

- Your list is stored **in the browser on that device only**. It is not synced between your phone and your computer.
- Always use the same link: a different address has its own, empty storage.
- Private browsing tabs clear the data when closed.
- Safari on iPhone may delete data of websites you haven't opened for about a week. An app added to the home screen is not affected.
- The page needs an internet connection to open until offline support is added.
- Use **Download backup** from time to time. The backup contains the items, the section order and the saved orders. It does not contain the remembered corrections or the theme.

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Page markup |
| `style.css` | Styles and the light/dark color variables |
| `index.js` | App logic: items, rendering, section order, saved orders, backup |
| `categories.js` | Section detection: corrections, keywords, model call |
| `model.js` | Trained model weights (generated by a training script, don't edit by hand) |
| `icons/` | Home screen icon |

The script order in `index.html` matters: `model.js`, then `categories.js`, then `index.js`.

## Tech stack

- HTML5
- CSS3
- JavaScript (no frameworks, no build step)

## How to run

Open `index.html` in your browser. No installation required.

Or serve the folder locally:

```bash
python3 -m http.server 8765
```

and open http://localhost:8765.

## Publishing

The site is served by GitHub Pages from the `main` branch. Every `git push` to `main` updates it within a minute or two.
