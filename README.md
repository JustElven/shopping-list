# Shopping List

A web app for your grocery list: add items, tick off what you've bought, and take the list with you to the store.

**Live app:** https://justelven.github.io/shopping-list/

> A learning project: I'm building it from scratch to learn HTML, CSS and JavaScript.

## Features

- [x] Add items with an optional quantity (for example `Milk`, `2 l`)
- [x] Mark items as bought, remove them one by one, or clear all bought items at once
- [x] Progress bar and counters: total items and how many are bought
- [x] Automatic section detection from the item name (see below)
- [x] Sections with a custom order: drag to reorder, swipe left to delete, add your own
- [x] Saved section orders: store several orders (for example one per store) and switch between them from the main screen
- [x] Russian and English: switch the interface language with the RU/EN button (the browser language is used at first)
- [x] Light and dark theme (follows the system setting until you pick one)
- [x] Save the list in the browser (`localStorage`)
- [x] Backup: download the list as a JSON file and restore it later
- [ ] Offline support (PWA)

## How section detection works

When you type an item name, the app picks a section in three steps, from the most precise to the most general.
It understands Russian and English names, whichever interface language is on:

1. **Your corrections.** If you change the suggested section by hand, the app remembers it for that item name.
2. **Keyword dictionaries.** The Russian one matches word stems ("молок" finds "молоко" and "молочный"). The English one matches whole words, plurals included (`tomato` finds "tomatoes", but `tea` doesn't fire on "steak"). The longest matching keyword wins, so "orange juice" goes to Drinks and not to Fruits & vegetables.
3. **Small ML models.** If no keyword matches, two logistic regression models (`model_ru.js` and `model_en.js`) make a guess from the letters of the name, and the more confident one wins. They are a fallback; the English one is right on roughly two out of three unfamiliar names.

If the model isn't sure either, the item goes to the "Other" section, which can't be deleted.
You can always change the section in the dropdown before adding the item, and the app will remember your choice.

## Languages

All interface texts live in `i18n.js`, one block per language. To add a language, add a block there and its code to `LANGS`.

Built-in sections are stored as language-neutral keys (`fruits_veg`, `dairy_eggs`, …), so switching the language only changes their labels. Sections you add yourself keep the name you typed. Lists saved earlier, with Russian or English section names, are converted to keys when they open.

## Using it on your phone

The live app is published with GitHub Pages, so a domain is not needed.

1. Open https://justelven.github.io/shopping-list/ on your phone.
2. Add it to the home screen: in Safari tap Share → Add to Home Screen, in Chrome choose Install app.

Good to know:

- Your list is stored **in the browser on that device only**. It is not synced between your phone and your computer.
- Always use the same link: a different address has its own, empty storage.
- Private browsing tabs clear the data when closed.
- Safari on iPhone may delete data of websites you haven't opened for about a week. An app added to the home screen is not affected.
- The page needs an internet connection to open until offline support is added.
- Use **Download backup** from time to time. The backup contains the items, the section order and the saved orders. It does not contain the remembered corrections or the theme.

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Page markup |
| `style.css` | Styles and the light/dark color variables |
| `index.js` | App logic: items, rendering, section order, saved orders, backup |
| `i18n.js` | Interface texts in Russian and English, section names, language switching |
| `categories.js` | Section detection: corrections, Russian and English keywords, model calls |
| `model_ru.js` | Russian model weights (generated by a training script, don't edit by hand) |
| `model_en.js` | English model weights (generated by `tools/train_model.py`, don't edit by hand) |
| `tools/dataset.json` | Example English product names per section, used to train the English model |
| `tools/train_model.py` | Training script that regenerates `model_en.js` |
| `icons/` | Home screen icon |

The script order in `index.html` matters: `i18n.js`, the two model files, `categories.js`, then `index.js`.

## How to run

Open `index.html` in your browser. No installation required.

Or serve the folder locally:

```bash
python3 -m http.server 8765
```

and open http://localhost:8765.

## Retraining the model

To teach the English model new products, add names to `tools/dataset.json` and run (needs Python with `scikit-learn`):

```bash
python3 tools/train_model.py
```

It prints the accuracy on held-out names and rewrites `model_en.js`. The keyword dictionaries live in `categories.js` and need no training. The Russian model comes from an earlier training run whose dataset is not in this repository.

## Publishing

The site is served by GitHub Pages from the `main` branch. Every `git push` to `main` updates it within a minute or two.
